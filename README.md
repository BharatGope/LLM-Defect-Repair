# An Empirical Evaluation of Large Language Models for Software Defect Detection and Automated Program Repair

Research project for FIST-2027.

## Scope

Empirical evaluation of LLM-based software defect detection and automated program repair on real-world Python defects.

## Experimental Conditions

1. LLM-only
2. Static analysis
3. Hybrid LLM + static analysis
